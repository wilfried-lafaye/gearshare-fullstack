# GearShare

Plateforme de prêt de matériel entre étudiants (module E5 — Fullstack data application).

> Projet réalisé en solo, avec l'accord oral de l'enseignant.

## Agent IA utilisé

Claude Code (Anthropic), et non GitHub Copilot : choix assumé, un second LLM étant autorisé. Les échanges sont dans `prompts/`, les contrôles dans `reviews/`.

## Démarrage

```bash
git clone https://github.com/wilfried-lafaye/gearshare-fullstack
cd gearshare-fullstack
cp .env.example .env
docker compose up
```
